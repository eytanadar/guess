GUESS: the Graph Exploration System

Version

A language and interface for exploring graphs. You query and change the network in Gython, a Python dialect with graph operators, and the console, the display, the tables and the charts all stay linked to each other.

Author
Eytan Adar
Version
(version 2, built )
Original
GUESS 1 (Java, 2006). E. Adar, “GUESS: A Language and Interface for Graph Exploration,” CHI 2006.
Runs on
Pyodide (Python in the browser), PixiJS, CodeMirror, Vega-Lite, Graphviz (WebAssembly) and the Eclipse Layout Kernel (elkjs)
