Cookbooks

Short, runnable recipes for one field each, all building on the GUESS Kitchen. Every book ends with a capstone: a small visual-analytics app. The data files each book uses are linked below it (in GUESS they're already there: just open them by name). Sources and licences: datasets README. All cookbooks
