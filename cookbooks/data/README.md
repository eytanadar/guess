# Cookbook datasets

| file | source | notes |
|---|---|---|
| `karate.gdf` | W. W. Zachary, "An information flow model for conflict and fission in small groups", *J. Anthropological Research* 33 (1977). Via networkx. | nodes `m1`–`m34` (label = Zachary's number); `club`; edge `weight` = contexts shared |
| `florentine.gdf` | J. F. Padgett and C. K. Ansell, "Robust action and the rise of the Medici, 1400–1434", *AJS* 98 (1993). Marriage ties, via networkx. | the isolated Pucci family is not included |
| `southern-women.gdf` | A. Davis, B. B. Gardner and M. R. Gardner, *Deep South* (1941). Via networkx. | nodes are women (first names) and events `E1`–`E14`; `kind` |
| `lesmis.gdf` | D. E. Knuth, *The Stanford GraphBase* (1993): co-appearances of characters in *Les Misérables*. Via networkx. | edge `weight` = chapters together |
| `friends.csv`, `friends-nodes.csv` | made up for the cookbooks | a small edge table with duplicates and a self-loop, and a node table |
| `../../gdfs/sample.gdf` | GUESS's example organisation | |
| `../../gdfs/adamic-glance.gdf` | L. Adamic and N. Glance, "The political blogosphere and the 2004 U.S. election" (2005): 40 prominent blogs, as distributed with GUESS since 2006 | directed |

The four networkx datasets are regenerated by `make_data.py`.
